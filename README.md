# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors game** built using **HTML, CSS, and JavaScript**. Play against the computer, see the result instantly, and keep track of your score.

## ✨ Features

* 🪨 Rock, 📄 Paper, and ✂️ Scissors choices
* 🤖 Play against the computer
* 🏆 Automatic winner/result detection
* 📊 Wins, losses, and ties score tracking
* 💾 Score persistence using `localStorage`
* 🔄 Reset score functionality
* 🎨 Simple and responsive user interface
* 🖼️ Custom game images/emojis

## 🛠️ Technologies Used

* **HTML5** — Structure of the game
* **CSS3** — Styling and layout
* **JavaScript** — Game logic and score management
* **LocalStorage** — Saving the game score

## 🎮 How to Play

1. Open the game.
2. Choose **Rock**, **Paper**, or **Scissors**.
3. The computer randomly selects its move.
4. The game displays the result.
5. Your score is automatically updated.
6. Click **Reset Score** to start the score again.

### Game Rules

| Your Move   | Computer Move | Result  |
| ----------- | ------------- | ------- |
| 🪨 Rock     | ✂️ Scissors   | You Win |
| 📄 Paper    | 🪨 Rock       | You Win |
| ✂️ Scissors | 📄 Paper      | You Win |
| Same        | Same          | Tie     |
